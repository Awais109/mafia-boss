# Sound

Sound effects, music and the cover's ambience ([ADR 0055](decisions/0055-sound.md)). The rules of what plays live in one pure file, so they're tested without a device. The player only plays them, and a sound with no file in the build plays its fallback or nothing. The game is whole with any subset of the files, including none.

**Code:**
- `app/sound/cues.ts`: the names, the mix, `eventCue`, `cueForEvents`, `pickSfx`, `pickMusic`, `SCENE_MUSIC`, `musicFor`. Pure.
- `app/sound/player.ts`: `sound`, the player over `expo-audio`.
- `app/sound/files.ts`: the manifest, generated by `npm run sounds`.
- `scripts/sounds.ts`: prepares files and writes the manifest.
- `assets/sounds/`: the files, with `CREDITS.md`.
- Settings: `app/screens/SettingsScreen.tsx`, and `setAudio` in `app/store.ts`.

## The rules

- **One sound per batch.** A dispatch or a tick plays `cueForEvents` of its events: the highest `priority` among them (`SFX` in `cues.ts`). A raid outranks the collect it came with.
- **One sound at a time.** Within `MIX.gapMs` of a sound, a lower or equal priority one is dropped. That's how the typewriter gives way to the phone that filed the decision.
- **Taps wait their turn.** A press's tap waits `MIX.tapDeferMs`. If the press made its own sound (a buy, a refusal), the tap doesn't play.
- **Away is one sound.** A catch-up long enough for the away summary makes no event sounds; the summary plays `away` once. A skip ahead plays `skip`, not what it skipped.
- **Music follows the screen** (`musicFor`): the cover, the playing scene (`SCENE_MUSIC`), or the game by act. Switching tracks fades out and in over `MIX.fadeMs`. Stings play once over the loop.
- **Fallbacks.** `pickSfx` and `pickMusic` walk a sound's `fallback` until one has a file. A loop never falls back to a sting.
- **Volumes** are per sound and per track (`SFX`, `MUSIC`). The files are evened out by `npm run sounds`, so the volumes set the mix. These are presentation numbers, not game numbers, so they live in `cues.ts`, not in `engine/config/defaults.ts`.

## The player

`sound` in `app/sound/player.ts`, started once by `App.tsx`:
- `setAudioModeAsync({ playsInSilentMode: false, interruptionMode: 'mixWithOthers', shouldPlayInBackground: false })`. It follows the silent switch, plays alongside the player's own audio without stopping it, and goes quiet in the background (`setIsAudioActiveAsync`), resuming the loops on return.
- One `AudioPlayer` per one-shot, made on first use. One loop player each for the music and the ambience, which `replace` their source and fade. One for stings.
- It's silent on web, which is only the screenshot rig.

The store calls `sound.play` after each dispatch and live tick. `App.tsx` sets the music and the cover's ambience. `ui.tsx` taps (`Btn`, `Item` with `onPress`, `BuyRow`, `Segmented`). The scene viewer plays each beat's sound, `AwayModal` plays `away`, and `EventNoticeModal` plays `typewriter`.

`app.json` configures the `expo-audio` plugin with no background playback and no microphone (`enableBackgroundPlayback`, `recordAudioAndroid` and `microphonePermission` all `false`), so the app asks for neither. `expo-asset` is a direct dependency at the SDK's version. `expo-audio` would otherwise pull in a newer major one that breaks the bundle.

## Settings

More → Settings: **Sound effects** and **Music**, each On or Off, both on by default. They're kept in `sevgorod-settings.json` as `audio: { sound, music }`. A settings file from before has the defaults. They're preferences, not config: `store.setAudio` writes the file and tells the player, with no log line and no `CONFIG_CHANGED`. Sound effects also cover the cover's ambience; music covers the stings. With no files in the build, the screen says so.

## Adding sounds

1. Put the file in `assets/sounds/raw/`, named after the sound: `stamp.wav`, `theme.m4a`. It can be wav, mp3, m4a, aif, aiff, flac, ogg or caf. `raw/` is ignored by git.
2. Run `npm run sounds`. It needs `ffmpeg` (macOS: `brew install ffmpeg`). It prepares each raw file newer than its mp3, then rewrites `app/sound/files.ts` from what's in `sfx/` and `music/`:
   - one-shots: mono, trimmed of silence at both ends with a few milliseconds' fade, peaked at −4 dB, 96 kbps;
   - stings: stereo, trimmed at the start only, peaked at −4 dB, 160 kbps;
   - loops: stereo, left whole, evened out to −20 LUFS (music) or −24 LUFS (ambience), 160 kbps.

   A file whose name isn't a sound is skipped with the list of names. An mp3 already prepared elsewhere can go straight into `sfx/` or `music/`, and the script only lists it.
3. Add a row to `assets/sounds/CREDITS.md`: source, author, license.
4. Hear it in Debug → Sound, which lists every name with its file, its fallback, or "missing", and plays it.

`tests/sound.test.ts` fails if `files.ts` and the folders disagree, so a file added without running the script is caught by `npm run check`.

**A new native module.** Expo Go has `expo-audio`, but a standalone install built before it has to be built again ([native-builds.md](native-builds.md)).

## Not built

- No volume sliders, only on and off.
- No ducking of the music under stings or scenes.
- No haptics.
- No sound for a district revealed on the map while you watch: `ink` plays when a district changes hands, and in the Empire's scene.
- The design brief's motion (a page turn, ink spreading, counters ticking up) isn't built; these sounds stand in for some of it.
